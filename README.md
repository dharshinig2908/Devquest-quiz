🚀 DevQuest — The Ultimate Tech Challenge

Challenge your coding knowledge. Build your skills. Become a legend.

DevQuest is an interactive, gaming-inspired quiz website designed to make learning web development fun and competitive. Test your knowledge, earn XP, maintain combo streaks, and discover your developer rank through a futuristic neon-themed interface.

✨ Features

- 🎯 Interactive Quiz: Answer technology-related multiple-choice questions.
- ⚡ XP & Scoring System: Earn experience points for correct answers.
- 🔥 Combo Streaks: Get bonus XP for consecutive correct answers.
- ⏱️ Countdown Timer: Challenge yourself to answer before time runs out.
- 💡 Hint System: Get helpful clues when you need assistance.
- 50️⃣ 50/50 Power-Up: Eliminate two incorrect options.
- 📊 Progress Tracking: Monitor your progress as you complete questions.
- 🏆 Final Results & Ranking: View your score, accuracy, XP, and rank.
- 🔄 Play Again: Restart the challenge and test yourself again.
- 📱 Responsive Design: Enjoy the quiz on desktop and mobile devices.
- 🌌 Neon Gaming UI: Explore a modern dark interface with glowing accents.

🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Responsive layout, styling, and animations
- JavaScript — Quiz logic, timer, scoring, and interactive features

No external JavaScript libraries or separate questions JSON file are required.

▶️ How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in your browser, or use the Live Server extension.
4. Click Start Quiz and begin your challenge.

🎮 How to Play

1. Start the quiz.
2. Read each question carefully.
3. Select the correct answer before the timer ends.
4. Use Hint or 50/50 when necessary.
5. Build your combo streak to earn bonus XP.
6. Complete the quiz and check your final rank.
